# Help Desk Home Lab

I started this project so I can get hands-on practice with help desk tasks and build my IT skills. My goal is to practice different problems, write down what I did, and keep screenshots of the results so I can show my work on GitHub and include it on my resume.

I am using a Windows 11 Enterprise evaluation virtual machine that I created with Hyper-V on my laptop. I finished setting up Windows, installed the updates, and created a clean baseline checkpoint. I also tested restoring the checkpoint, and it worked.

For each lab, I plan to document the problem, what I checked, the steps I took, and how I verified the result. Before restoring the VM, I will save my notes and screenshots outside of it so I can keep a record of each completed project.

This project is still in progress. The VM setup is complete, and I will add more labs as I finish them. These are practice projects in my home lab.
